# Notes App

The main goal was to explore modern Next.js patterns:

- App Router and Server Components
- Server-side rendering
- Cache Components
- Suspense and loading states
- Server/client component boundaries
- tRPC for server-side data fetching
- React Compiler
- Feature-based architecture

## Tech Stack

Next.js, React, TypeScript, Drizzle, Neon, Better Auth, tRPC, Tailwind CSS, and BlockNote.
